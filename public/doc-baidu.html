入参与响应同百度翻译开放平台「通用文本翻译」，已有百度 SDK / 代码可直接换地址接入
本服务 Base URL：https://your-gateway.example.com（即当前页面的访问地址）
鉴权凭据：appid 填任意非空字符串（如 gateway）；密钥 填网关管理员发放的网关对外 AUTH_KEY。

POST/baidu/api/trans/vip/translate — 通用文本翻译

POST {base}/baidu/api/trans/vip/translate

同时支持 POST（推荐，form 表单或 JSON）与 GET（query 参数）。多行文本在 q 内用 \n 分隔，响应逐行对应。

参数必填说明
q必填请求翻译文本（UTF-8），≤ 6000 字符；\n 分隔多行
from可选源语言，auto 或留空为自动检测
to必填目标语言（见下方语言代码表）
appid必填任意非空字符串即可（网关以密钥鉴别身份）
salt必填随机数（数字或字符串均可）
sign必填签名，见下方生成方法

SIGN签名生成方法

将 appid + q + salt + 密钥 按顺序拼接后计算 MD5，取 32 位小写十六进制即为 sign（与百度官方规则一致，q 为未 URL 编码的 UTF-8 原文）。

# 签名示例
sign = MD5( appid + q + salt + 密钥 ).hexdigest()   # 32 位小写
# curl 示例
curl -X POST "https://your-gateway.example.com/baidu/api/trans/vip/translate" \
  --data-urlencode "q=Hello, world!" \
  -d "from=en&to=zh&appid=gateway&salt=1435660288" \
  -d "sign=$(echo -n "gatewayHello, world!1435660288YOUR_GATEWAY_KEY" | md5sum | cut -d' ' -f1)"
# Python 示例
import hashlib, requests, random, uuid

APP_ID = "gateway"            # 任意非空字符串
SECRET = "YOUR_GATEWAY_KEY"   # 网关对外密钥
BASE   = "https://your-gateway.example.com/baidu/api/trans/vip/translate"

q, salt = "Hello, world!", str(random.randint(1, 10**9))
sign = hashlib.md5((APP_ID + q + salt + SECRET).encode("utf-8")).hexdigest()
r = requests.post(BASE, data={ "q": q, "from": "en", "to": "zh",
                               "appid": APP_ID, "salt": salt, "sign": sign })
print(r.json())
// Node.js 示例
const crypto = require("crypto");
const APP_ID = "gateway", SECRET = "YOUR_GATEWAY_KEY";
const BASE = "https://your-gateway.example.com/baidu/api/trans/vip/translate";

const q = "Hello, world!", salt = String(Date.now());
const sign = crypto.createHash("md5")
  .update(APP_ID + q + salt + SECRET, "utf8").digest("hex");

const resp = await fetch(BASE, {
  method: "POST",
  headers: { "Content-Type": "application/x-www-form-urlencoded" },
  body: new URLSearchParams({ q, from: "en", to: "zh", appid: APP_ID, salt, sign }),
});
const data = await resp.json();
// 成功响应（200）— 与百度通用翻译结构一致
{

  "to": "zh",

  ]

路由说明：百度渠道仅是接入风格，实际翻译由网关按优先级 + 剩余额度在多家上游中自动路由，无需百度账号。

错误格式

与百度一致：HTTP 200 + { "error_code": "<码>", "error_msg": "..." }

error_code含义
52002系统错误（网关上游全部不可用，请重试）
54000必填参数为空（q / to / appid / salt / sign）
54001签名错误（检查 sign 拼接顺序与密钥）
58003q 长度超限（≤ 6000 字符）
