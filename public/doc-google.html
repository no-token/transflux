本服务 Base URL：https://your-gateway.example.com（即当前页面的访问地址）
鉴权：URL 追加 &token=<网关对外 AUTH_KEY>，或请求头 Authorization: Bearer <网关密钥>

SETUP沉浸式翻译配置方法

  1. 打开沉浸式翻译「设置」→「开发者设置」；
  2. 在「编辑用户配置（User Config）」的 translationServices 中加入（或直接在翻译服务 → 谷歌翻译的「接口地址 / API 地址」字段填写）：
    "google": { "apiUrl": "https://你的域名/google/translate_a/single?token=你的网关密钥" }
    客户端会自动带上 client=gtx&sl=&tl=&q= 等参数，网关只替换地址；
  3. 保存后切换网页翻译服务为「谷歌翻译」即可。

版本兼容：沉浸式翻译并非所有版本/所有服务都开放「接口地址」自定义（如百度翻译服务不支持）。若你的版本在谷歌翻译设置或开发者配置里找不到接口地址字段，请改用「自定义 API」渠道（/imme），翻译效果等同。

GET/google/translate_a/single — 网页翻译

GET {base}/google/translate_a/single?client=gtx&sl=auto&tl=zh-CN&q=Hello

同时支持 GET 与 POST（query / JSON / form）。q 可重复传多段，段内可用 \n 分行；响应与输入行一一对应。client、dt 等参数忽略。

参数必填说明
q必填翻译文本；可重复传多段，总长 ≤ 10000 字符
tl必填目标语言（Google 代码：zh-CN / zh-TW / en / ja …）
sl可选源语言，auto 或省略为自动检测
token必填网关对外 AUTH_KEY（或用 Bearer 头传递）
 
# curl 示例
curl "https://your-gateway.example.com/google/translate_a/single?client=gtx&sl=auto&tl=zh-CN&q=Hello,%20world!&token=YOUR_GATEWAY_KEY"
// 成功响应（200）— 与 Google translate_a/single 结构一致
[
  [
    [ "你好，世界！", "Hello, world!", null, null ]
  ],
  null,
  "en"
]

说明：data[0] 为 [译文, 原文, null, null] 数组，与 q 内的文本行一一对应；data[2] 为检测到的源语言。实际翻译由网关按优先级 + 额度在多家上游中自动路由。

错误格式

HTTPbody含义
400{ "error": "Missing required params: tl and q" }缺 tl / q 或 q 为空、超长
401{ "error": { "code": "unauthorized" } }token 缺失或错误
503{ "error": "Translation failed, please retry" }上游全部失败，请重试
